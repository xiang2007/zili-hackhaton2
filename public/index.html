Read before use

What this dashboard can—and cannot—decide

It supports heat screening and scenario comparison across the supplied telecom observations. Low, Medium, and High use the source breakpoints <32 °C, 32–<38 °C, and ≥38 °C.

The smooth default surface is extracted from the supplied baseline LST layout and registered to the matching study extent. Exact numeric inspection still comes from the evidence grid and model records.

The thermal exposure grid aggregates modelled land-surface temperature. It is not a full Heat Vulnerability Index because no demographic sensitivity or adaptive-capacity attributes were supplied.

Proposed-site scores combine a lower-temperature preference with distance to the nearest supplied telecom record. They are preliminary and must pass the approval gates.
