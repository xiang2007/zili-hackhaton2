# Phase 6 completion and handoff checklist

## Built in this release

- [x] Interactive Leaflet dashboard with heat overlays, 45,660 telecom records, inspection, layer controls, and scenario updates.
- [x] V6 baseline LST means plus smoothed, dynamically regenerated scenario and exposure surfaces.
- [x] Predictive Scenario Tool with proposed-site screening, transparent weighting, CSV register, and printable board memo.
- [x] Inspectable 56-area UHVI v6 choropleth, GeoJSON/CSV exports, source PDF, class metadata, data dictionary, and operational restrictions.
- [x] KLCAP2050/PSKL2040 summary and alignment crosswalk.
- [x] DBKL/MBSA/MBPJ briefing deck and facilitation guide.
- [x] Feedback form, JSON export, task protocol, severity model, and acceptance targets.
- [x] Static deployment runbook, reproducible data build, validation script, release archive, and checksums.

## Requires owner action before operational publication

- [ ] Conduct stakeholder presentation and record decisions.
- [ ] Run two usability rounds and close acceptance findings.
- [ ] Obtain custodian sign-off on the supplied UHVI v6 geometry, method, component vintages, uncertainty and stable area identifiers.
- [ ] Supply official canopy, land use, population/facility, intervention, and engineering layers.
- [ ] Complete security, infrastructure-disclosure, privacy, accessibility, and statutory review.
- [ ] Approve accountable owners, hosting target, access model, retention class, and review cadence.
- [ ] Publish the approved build and record the production URL and release checksum.

The unchecked items require municipal authority, stakeholder participation, or authoritative data and cannot be truthfully completed by the software build alone.
